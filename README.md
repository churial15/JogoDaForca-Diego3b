# Melhoramento do *Jogo da forca* em linguagem python

## Neste jogo da forca está adicionado categorias como:
- Jogos;
- Músicas;
- Bandas;
- Tecnologia.

### Este é projeto educacional de um **Jogo da Forca** clássico implementado em Python, desenvolvido para a disciplina de **Programação no Desenvolvimento** de Sistemas (3º Ano do Ensino Médio Técnico).

### O jogo foi aprimorado com as seguintes features:

-  **Sistema de dificuldades** (Fácil, Médio, Difícil e Extremo);
-  **Representação visual da forca** durante o jogo;
-  **Sistema de pontuação** com bônus e penalidades;
-  **Validação robusta** de entrada do usuário.

## Sistema de Pontuação:
- ✅ **Acerto**: +10 pontos
- ❌ **Erro**: -2 pontos

## 🎨 Visualização da Forca

O jogo exibe uma representação ASCII da forca que evolui conforme você erra:
  +---------+
  |         |
  |         O
  |        /|\
  |        / \
  |
  +-----
